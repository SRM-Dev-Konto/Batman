# Team Batman Snake

## Run

```bash
npm install
node server.js
```

Open the local URL on your laptop, create a room, and scan the QR code from another device on the same network.

## Controls

- Laptop: Arrow keys or WASD
- Mobile: touch buttons or swipe on the board

## Notes

- Every player enters a 5-letter name.
- Each connection creates a new snake.
- The scoreboard updates live.
- One tunnel pair is present on the board.
- The AI snake moves at the same tick speed as players.
